# Face select tool. 
When selecting by similar angle, also allow selecting using a line that you draw. Instead of selecting individual tris however, it selects those tris and any joined less than the tolerance angle.

# Model Tag tool
Just like the raft tag tool, but this can connect to a model that might be sitting on the plate and doesnt need a raft. It might not be able to use the same logic for placement as the raft tool, since the raft is a predictable geomertry and can be automatically placed tangenetial to it. This tool might need to be placed and rotated manually.

# Model Text tool
Allows adding extruded text anywhere on the model.

# Combine multiple models into one
They dont have to be booleaned cleanly (maybe), but can just be saved as one model. This could be useful when people want to use cad designed support structures, then place supports between that structure and the model. It could also be useful for people who want to combine multiple models into one for printing, but dont want to have to boolean them together.

# Cages
Create a cage around a model to protect it during shipping.
